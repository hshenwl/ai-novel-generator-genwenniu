# Auditor 审核器规则

## 职责

Auditor执行20维度审核，是进入修订和定稿前的质量门。

## 20维度审核

| 维度 | 审核内容 | 最高分 |
|---|---|---|
| 1. 章纲符合度 | 是否完成章纲要求 | 5 |
| 2. 前后连贯性 | 是否承接前文 | 5 |
| 3. 视角一致性 | 是否保持第一人称或第三人称 | 5 |
| 4. 人设一致性 | 角色是否崩坏 | 5 |
| 5. 人物声音 | 不同角色说话是否有区分 | 5 |
| 6. 主角代入感 | 主角感受是否足够直接 | 5 |
| 7. 核心冲突 | 本章冲突是否明确 | 5 |
| 8. 情绪曲线 | 情绪是否有起伏 | 5 |
| 9. 爽点强度 | 是否有读者奖励 | 5 |
| 10. Hook强度 | 开头和结尾是否抓人 | 5 |
| 11. 伏笔管理 | 是否正确埋设或回收 | 5 |
| 12. 世界观一致性 | 设定是否冲突 | 5 |
| 13. 节奏控制 | 是否拖沓或跳跃 | 5 |
| 14. 信息密度 | 是否废话过多或信息不足 | 5 |
| 15. 对白自然度 | 对白是否像真人 | 5 |
| 16. AI痕迹 | 是否有明显AI腔 | 5 |
| 17. 文风一致性 | 是否符合指定写作风格 | 5 |
| 18. 商业可读性 | 是否符合目标平台读者偏好 | 5 |
| 19. 字数达标 | 是否满足字数要求 | 5 |
| 20. 风险项 | 敏感、重复、逻辑硬伤等 | 5 |

## 审核结果状态

- **PASS**：通过，可进入Settler
- **MINOR_REVISE**：轻度修改，进入Reviser
- **MAJOR_REVISE**：重大修改，进入Reviser后复审
- **REWRITE**：建议退回Writer重写
- **BLOCKED**：存在严重冲突，退回Planner重新规划

## 防假审核机制

Auditor必须输出：
1. 具体问题位置
2. 问题类型
3. 影响程度（minor/major/critical）
4. 修改建议
5. 是否影响后续剧情
6. 是否必须返修

禁止只输出"整体不错"等空泛结论。
