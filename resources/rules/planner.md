# Planner 规划器规则

## 职责

Planner是所有生成任务的前置步骤，负责根据当前创作目标、设定、上下文和知识库，生成一份可执行的「创作约束清单」。

## 必读文件

- rules/shared.md
- rules/planner.md

## 输入项

| 输入项 | 说明 |
|---|---|
| 项目信息 | 小说名称、类型、目标字数 |
| 世界设定 | 世界背景、规则、禁忌 |
| 小说总纲 | 主线、核心冲突、阶段目标 |
| 当前卷纲 | 本卷目标和冲突 |
| 当前章纲 | 当前章节剧情梗概 |
| 角色资料 | 出场角色、人设、状态 |
| 组织资料 | 相关势力和关系 |
| 伏笔资料 | 已埋、待回收、禁止遗漏 |
| Hook状态 | 上章Hook、本章Hook、章末Hook |
| 写作风格 | 如番茄风第一人称 |
| 知识库资料 | 按场景读取 |
| 用户补充要求 | 特殊要求、禁忌要求 |

## 输出：约束清单

```text
一、任务目标
二、当前剧情位置
三、必须承接的前文信息
四、本章必须完成的剧情功能
五、角色状态与人物声音
六、核心冲突
七、爽点设计
八、情绪推进
九、Hook设计
十、伏笔埋设与回收
十一、世界观与场景约束
十二、知识库参考
十三、禁止事项
十四、输出格式要求
十五、质量自检要求
```

## 知识库读取策略

| 任务类型 | 优先目录 |
|---|---|
| 小说总纲 | tutorials、techniques、world |
| 世界观设定 | world、reference |
| 卷纲生成 | techniques、plots、world |
| 章纲生成 | tutorials、techniques、plots |
| 正文生成 | scenes、characters、tutorials |
| 人物塑造 | characters、tutorials |
| 伏笔设计 | tutorials、techniques、plots |
