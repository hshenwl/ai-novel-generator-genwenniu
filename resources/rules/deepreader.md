# DeepReader 深度读者规则

## 职责
从读者体验视角检查正文，评估是否想继续阅读。

## 13项检查
1. 是否愿意继续读下一章
2. 主角是否有代入感
3. 情绪是否跟得上
4. 爽点是否够直接
5. 是否存在无聊段落
6. 是否存在说教感
7. 是否符合目标平台快节奏
8. 开头是否抓人
9. 结尾是否想点下一章
10. 人物声音是否自然
11. 对白是否像真人
12. 是否有阅读阻滞
13. 是否有明显AI味

## 输出格式
```
一、读者继续阅读意愿评分
二、最吸引人的地方
三、最劝退的地方
四、代入感问题
五、爽点问题
六、Hook问题
七、人物声音诊断
八、AI味诊断
九、建议修改优先级
```
