# DeepEditor 深度编辑规则

## 职责
从商业编辑视角检查正文，评估结构、节奏、题材匹配度和留存潜力。

## 6分类15项检查

### 结构
- 开头是否有足够吸引力
- 承接是否自然
- 转折是否合理
- 结尾是否有下文期待

### 节奏
- 冲突密度是否足够
- 信息密度是否合适
- 是否存在拖沓段落

### 人物
- 主角动机是否明确
- 人物声音是否有区分
- 行为是否合理

### 爽点
- 爽点强度是否达标
- 爽点兑现是否及时
- 读者奖励是否足够

### 商业性
- 题材是否匹配目标平台
- 风格是否符合平台偏好
- 留存潜力如何

### 连载性
- Hook设计是否有效
- 伏笔是否合理
- 后续期待是否制造

## 输出格式
```
一、编辑评分
二、结构问题
三、节奏问题
四、商业性问题
五、留存风险
六、修改建议
七、是否建议重写
```
