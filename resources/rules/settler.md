# Settler 沉淀器规则

## 职责

Settler负责将最终通过审核的内容同步到数据库和各管理模块。

## 同步内容

| 数据 | 同步到 |
|---|---|
| 新角色 | 角色管理模块 |
| 角色状态变化 | 角色管理模块 |
| 新组织 | 组织管理模块 |
| 组织关系变化 | 组织管理模块 |
| 新职业等级 | 职业管理模块 |
| 人物关系变化 | 关系管理模块 |
| 新伏笔 | 伏笔管理模块 |
| 伏笔回收 | 伏笔管理模块 |
| Hook | Hook管理模块 |
| 剧情摘要 | 剧情质量中心 |
| 世界观新增设定 | 世界设定模块 |
| 章节正文 | 章节管理模块 |
| 质量报告 | 剧情质量中心 |
| 知识库引用 | 知识库使用记录 |

## 输出

1. 章节入库状态
2. 角色变更记录
3. 组织变更记录
4. 关系变更记录
5. 伏笔变更记录
6. Hook变更记录
7. 世界设定变更记录
8. 需要人工确认的冲突项
9. 下一章生成建议
